# MarkdownEditor 아키텍처

## 계층

- `core.file_io`: 입력 검증, 인코딩·BOM·줄바꿈 문서 모델, 원자 저장
- `core.naming`: 날짜 파일명과 충돌 순번(다른 탭에 열린 경로를 건너뛰는 조건 포함)
- `core.md_actions`: 툴바가 사용하는 순수 텍스트 변환
- `core.editing`: 공백 2칸 들여쓰기와 Markdown 줄바꿈 접두사 계산
- `core.renderer`: Markdown 파싱, front matter·Mermaid 변환, HTML 정화
- `core.links`: 연결 요소 추출, 문서 폴더 기준 경로 해석
- `core.view_settings`: 편집기 글간격의 기본값·단계·범위와 설정값 해석(Qt 없음)
- `core.opening`: 열린 문서의 중복 판정 키, 끌어다 놓은 항목 분류, 열기 결과 요약(Qt 없음)
- `gui.editor`: 줄 번호·구문 강조 편집기. 글자 크기와 글간격을 따로 보관해 글꼴을 한곳에서 만듦
- `gui.fonts`: 번들 Pretendard 등록, 글자 크기 범위, `editor_font(size, spacing)`, WebEngine용 글꼴 CSS
- `gui.preview`: QtWebEngine 셸, CSP, Mermaid, 링크 브리지, 앱 전체에 하나인 외부 요청 차단기
- `gui.toolbar`: 서식 명령 `QAction` 모음(`MarkdownActions`, 창마다 한 벌)과 탭마다 만드는 툴바 위젯
- `gui.document_session`: 탭 하나의 문서·편집기·미리보기·렌더·동기화 상태(`DocumentSession`)
- `gui.file_drop`: 모든 끌어다 놓기 대상이 함께 쓰는 이벤트 필터(`FileDropController`)
- `gui.main_window`: 메뉴·액션, 전역 보기 설정, 탭·시작 화면, 공통 열기 경로, 저장·닫기·종료 조정

## 문서 세션과 탭

탭 하나는 `DocumentSession` 하나입니다. 세션이 탭 페이지 위젯을 만들고, 그 안에 툴바 위젯·편집기(왼쪽)와 미리보기(오른쪽)를 둡니다. 세션은 탭 인덱스가 아니라 탭 페이지 위젯으로 찾기 때문에 탭 순서를 바꿔도 저장·닫기 대상이 바뀌지 않습니다.

| 상태 | 소유 |
|---|---|
| `LoadedDocument`(경로, 인코딩·BOM·줄바꿈, 원본 바이트) | 세션 |
| 편집기(글, 실행 취소 기록, 수정 여부, 커서·선택, 스크롤) | 세션 |
| 미리보기(문서 기준 폴더, DOM, 스크롤) | 세션 |
| 렌더 타이머·revision·마지막 결과, 연결 요소 점검 결과 | 세션 |
| Sync Scroll 타이머와 되먹임 방지 플래그 | 세션 |
| 메뉴, `QAction`, 단축키 | `MainWindow` |
| 다크 모드, 글자 크기, 글간격, 들여쓰기, 자동 줄바꿈, 외부 이미지, Sync Scroll 켜짐, 보기 모드 | `MainWindow`(모든 세션에 전달) |
| 최근 파일, 창 위치, 연결 문제 패널, 상태 표시줄, 찾기 창 | `MainWindow`(활성 세션 내용을 표시) |
| 외부 요청 차단기, 렌더 스레드 풀 | 앱 전체에 하나 |

`MainWindow.editor`, `.preview`, `.document_data` 같은 이름은 활성 세션의 값을 돌려주는 읽기 전용 속성입니다. 문서가 없으면 `None`이고, 이때는 탭 대신 시작 화면(안내 문구, 열기 버튼, 최근 파일)을 보여 주며 문서 액션을 비활성화합니다.

## 공통 열기 경로

`파일 > 열기`(여러 개 선택), 최근 파일, 명령줄 인자(여러 개), 미리보기의 `.md` 링크, 도움말, 끌어다 놓기가 모두 `MainWindow.open_paths()`를 거칩니다. 경로마다 `core.opening.document_key()`(실제 경로 + 대소문자 무시)와 `os.path.samefile()`로 이미 열린 탭을 찾고, 있으면 그 탭을 활성화합니다. 없으면 `load_document()`로 검증해 새 세션을 만듭니다. 결과는 `열림 · 이미 열림 · 건너뜀 · 실패` 수로 상태 표시줄에 요약하고, 실패가 있을 때만 대화상자 하나로 이유를 보여 줍니다. 여러 파일을 한 번에 열면 마지막 탭만 바로 렌더링하고, 나머지 탭의 WebEngine 셸은 처음 볼 때 불러옵니다.

## 액션 라우팅

편집 메뉴, 서식 명령, 찾기·바꾸기, 줄로 이동, 미리보기 새로 고침, 저장은 실행되는 순간의 활성 세션에 적용됩니다. 서식 `QAction`은 `MarkdownActions`가 창마다 한 번만 만들고, 탭마다 있는 툴바 위젯은 같은 액션 객체를 표시합니다. 그래서 `Ctrl+B` 같은 단축키가 탭 수와 관계없이 하나이고, 제목 수준 콤보 상자만 탭마다 따로 만듭니다. 찾기·바꾸기 창은 탭을 바꾸면 대상 편집기를 활성 탭으로 바꿉니다. `탭 닫기`는 `QKeySequence.StandardKey.Close`의 모든 키(Windows: `Ctrl+W`, `Ctrl+F4`)를 씁니다. 탭 표시줄의 오른쪽 클릭 메뉴(`MainWindow.tab_context_menu()`)와 가운데 단추 닫기(탭 표시줄 이벤트 필터)는 누른 위치의 탭을 대상으로 하며, `다른 탭 닫기`·`모든 탭 닫기`는 탭 순서대로 `close_session()`을 불러 첫 [취소]에서 멈춥니다. 보기 모드는 배타적 `QActionGroup`이고, 보기 모드와 자동 줄바꿈은 `view/mode`, `view/word_wrap`에 저장합니다.

## 렌더 흐름

편집기 변경 신호는 300ms debounce 타이머를 다시 시작합니다. 세션은 revision 번호를 붙인 렌더 작업을 공유 스레드 풀에 넣고, 결과는 세션 객체의 슬롯으로 받습니다. 세션이 닫혔거나 revision이 최신이 아니면 결과를 버리므로 늦게 끝난 렌더가 다른 탭이나 닫힌 탭에 적용되지 않습니다. 미리보기 셸은 문서 폴더를 기준 URL로 사용하며 본문 컨테이너만 교체합니다. 셸 JavaScript가 이미지 상태와 Mermaid를 처리하고 완료 정보를 Python 브리지로 보냅니다. 미리보기의 재확인 타이머는 미리보기 객체를 문맥으로 걸어 두어 탭을 닫으면 함께 취소됩니다.

Mermaid는 라이트 모드에서 기본 테마, 다크 모드에서 `base` 테마와 별도 색상 변수를 사용해 다시 렌더링합니다. 다크 CSS는 flowchart·sequenceDiagram의 선, 화살표, 레이블에만 제한적으로 보정 색상을 적용합니다. 브라우저 진단 함수는 실제 렌더된 SVG의 계산된 색상으로 배경 대비를 구해 GUI 테스트와 샘플 인수 검증에서 4.5:1 이상인지 확인합니다.

## 화면 상태와 스크롤

라이트·다크 모드, 공통 글자 크기, 편집기 글간격(`view/letter_spacing`), `Sync Scroll`, 자동 들여쓰기 선택은 `QSettings`에 보관합니다. 편집기와 WebEngine 미리보기는 같은 Pretendard 자산과 배율을 사용합니다. 글간격은 `QFont.SpacingType.PercentageSpacing`으로 편집기 본문에만 적용하고, 줄 번호 영역은 100% 글꼴로 따로 그려 폭을 계산합니다. 현재 탭은 탭 표시줄 스타일(위쪽 굵은 막대와 굵은 글씨)로 표시합니다.

렌더러는 Markdown 블록과 원문 HTML 블록에 `data-line` 기준점을 넣습니다. 편집기에서 Viewer로 이동할 때는 첫 번째 보이는 원문 줄과 앞뒤 기준점 사이를 보간해 Viewer 좌표를 계산합니다. Viewer에서 편집기로 이동할 때는 같은 보간식을 역으로 적용해 원문 줄을 구하고 해당 편집기 블록을 상단으로 이동합니다. 스크롤 이벤트는 30ms 단일 실행 타이머로 합치고, 상대 창에 적용한 이동은 되먹임을 억제해 무한 왕복을 막습니다. 이 동기화는 각 탭 안에서만 일어나며, `Sync Scroll` 체크 상자는 탭마다 있지만 값은 하나라 한 탭에서 바꾸면 다른 탭의 체크 상자도 신호 없이 맞춥니다. `Sync Scroll 위치맞춤`은 같은 줄 매핑을 체크 상태와 무관하게 한 번 강제 실행합니다.

## 끌어다 놓기 이벤트 경로

Qt는 끌어다 놓기 이벤트를 커서 아래에서 끌어다 놓기를 받는 가장 안쪽 위젯에 보냅니다.

- 편집기: `QPlainTextEdit`의 viewport가 받습니다. `FileDropController`를 편집기와 viewport에 설치하고, 로컬 파일이 들어 있는 드래그만 가로챕니다. 로컬 파일이 없으면(편집기 안 글 옮기기, 다른 앱의 글, 웹 링크 글) 기본 동작으로 넘깁니다.
- 미리보기: `QWebEngineView` 안의 렌더 위젯(`focusProxy()`)이 받습니다. 뷰와 뷰에 나중에 추가되는 자식 위젯에 필터를 설치하고, 가로챈 이벤트는 Chromium에 넘기지 않습니다. 페이지 설정 `NavigateOnDropEnabled=False`를 둡니다.
- 탭 표시줄, 시작 화면, 툴바, 상태 표시줄: 끌어다 놓기를 받지 않으므로 Qt가 `MainWindow`로 올려 보내고, 같은 처리기를 씁니다.

처리기는 `core.opening.classify_drop()`으로 마크다운 확장자의 로컬 파일만 순서대로 고르고, 열 수 있는 파일이 있을 때만 드래그를 받습니다. 받을 때는 항상 `CopyAction`으로 응답하고(`acceptProposedAction()`을 쓰지 않음) 파일은 읽기만 합니다. 실제 열기는 다음 이벤트 루프로 미뤄 Explorer의 드래그가 먼저 끝나게 합니다. 열 수 있는 파일이 없으면 드래그를 거부하고, Qt가 이후 Drop을 보내지 않으므로 이유는 드래그 중 상태 표시줄에 보여 줍니다.

## 보안 경계

1. Python HTML 정화기가 active content를 제거합니다.
2. 셸 CSP가 허용된 앱 스크립트와 로컬 이미지 외 실행을 제한합니다.
3. WebEngine page가 셸 밖 navigation을 차단합니다. 링크 클릭은 브리지로만 처리하고, 메인 프레임 이동은 셸 로드(`data:`)와 Chromium 내부 `about:`만 허용하므로 파일을 끌어다 놓아도 셸이 바뀌지 않습니다.
4. 링크는 최소 기능의 QWebChannel 브리지로 Python에 전달합니다.
5. 외부 이미지는 사용자가 켜기 전까지 허용하지 않습니다. 모든 탭이 같은 기본 WebEngine 프로필을 쓰므로 요청 차단기(`NetworkGuard`)는 앱 전체에 하나만 설치하고, 탭을 닫아도 해제하지 않습니다. 마지막 창이 닫힐 때만 해제합니다.

## 저장 흐름

원본을 열 때 원본 바이트와 형식 메타데이터를 보관합니다. 편집하지 않은 저장은 원본 바이트를 그대로 새 날짜 파일에 씁니다. 편집 저장은 원래 인코딩·BOM·대표 줄바꿈을 적용합니다. 같은 폴더의 임시 파일을 flush·fsync한 후 `os.replace`로 교체합니다. 저장은 활성 세션에만 적용되며, 저장 대상(날짜 파일, 번호 붙인 대안, 다른 이름으로 저장 경로)이 다른 탭에 열린 파일이면 덮어쓰지 않습니다.

## 종료

탭을 닫을 때는 세션 타이머를 멈추고 세션을 닫힘 상태로 표시한 뒤 미리보기 페이지를 해제하고 탭을 제거합니다. 창을 닫을 때는 수정된 탭마다 저장 여부를 묻고, 하나라도 취소하면 종료를 멈춥니다. 종료가 확정되면 모든 세션을 정리하고 렌더 스레드를 최대 5초 기다립니다. `app.py`도 종료 후 모든 세션을 정리하고 요청 차단기를 해제합니다(탭이 0개여도 안전).
