# MarkdownEditor 사용설명서

## 1. 설치

1. Windows에 uv를 설치합니다.
2. MarkdownEditor 프로젝트 폴더를 준비합니다. `.venv` 폴더는 다른 PC에서 복사하지 않습니다.
3. `run_markdowneditor.bat`를 실행합니다. 처음 한 번은 Python과 필요한 패키지를 내려받아 시간이 걸릴 수 있습니다.

## 2. 문서 열기

- 메뉴에서 `파일 > 열기`를 선택하거나 `Ctrl+O`를 누릅니다. 대화상자에서 `Ctrl`이나 `Shift`를 누른 채 여러 파일을 고르면 한 번에 열립니다.
- 파일 탐색기의 Markdown 파일을 편집기, 미리보기, 탭 표시줄 또는 문서가 없을 때의 시작 화면에 끌어다 놓아도 됩니다. `run_markdowneditor.bat` 위에 여러 파일을 끌어다 놓아도 됩니다.
- 여는 파일마다 새 탭이 생기고 이미 열린 탭은 그대로 남습니다. 이미 열려 있는 파일을 다시 열면 새 탭을 만들지 않고 그 탭으로 이동합니다.

지원 확장자는 `.md`, `.markdown`, `.mdown`, `.mkd`, `.mkdn`입니다. UTF-8, UTF-16, CP949 문서를 지원합니다.

## 3. 화면 구성

- 맨 위: 열린 문서마다 하나씩 있는 문서 탭(현재 탭은 위쪽 파란 막대와 굵은 글씨, 수정한 탭은 ` *`)
- 왼쪽 위: Markdown 서식을 넣는 툴바
- 왼쪽: 줄 번호가 있는 원문 편집기
- 오른쪽: 표, 이미지, 링크, Mermaid를 보여 주는 미리보기
- 오른쪽 위: 편집기와 미리보기 위치를 맞추는 `Sync Scroll`과 `Sync Scroll 위치맞춤`
- 아래: 파일 경로, 인코딩, 줄바꿈, 커서 위치, 연결 문제, 렌더 시간, 글자 크기 `-`/`+`, 편집기 글간격(`간격 100%`)을 보여 주는 상태 표시줄

## 3-1. 문서 탭 사용하기

1. `파일 > 열기`로 첫 문서를 엽니다. 맨 위에 문서 이름이 적힌 탭이 생깁니다.
2. 다른 문서를 열면 탭이 하나 더 생깁니다. 첫 문서는 닫히지 않고 그대로 남습니다.
3. 탭 이름을 누르거나 `Ctrl+Tab`(다음 탭), `Ctrl+Shift+Tab`(이전 탭)으로 문서를 바꿉니다. 탭마다 편집기와 미리보기가 따로 있어 커서 위치, 실행 취소 기록, 스크롤 위치가 섞이지 않습니다.
4. 탭 이름을 마우스로 끌면 순서를 바꿀 수 있습니다. 탭에 마우스를 올리면 파일 전체 경로가 보입니다.
5. 탭의 `×`를 누르거나 `Ctrl+W`, 또는 탭을 마우스 가운데 단추(휠)로 눌러 탭을 닫습니다.
6. 탭을 마우스 오른쪽 단추로 누르면 `탭 닫기`, `다른 탭 닫기`, `모든 탭 닫기`, `파일 위치 열기`(파일 탐색기로 폴더 열기), `전체 경로 복사`가 나옵니다. `다른 탭 닫기`와 `모든 탭 닫기`는 `파일` 메뉴에도 있습니다.

### 탭별 저장과 닫기

- `Ctrl+S`와 `다른 이름으로 저장`은 지금 보고 있는 탭의 문서에만 적용됩니다. 다른 탭의 수정 표시(`*`)는 그대로 남습니다.
- 수정한 탭을 닫으면 "'파일 이름'의 변경 내용을 저장할까요?"라는 창에서 [저장] [저장 안 함] [취소]를 고릅니다. [취소]를 누르거나 저장하지 못하면 탭은 닫히지 않습니다.
- 프로그램을 끝낼 때 수정한 탭마다 같은 창이 나옵니다. 중간에 [취소]를 누르면 프로그램이 끝나지 않고 모든 탭이 남습니다.
- `다른 탭 닫기`나 `모든 탭 닫기`도 수정한 탭마다 같은 창을 보여 주고, [취소]를 누르면 그 탭부터는 닫지 않고 멈춥니다.
- 마지막 탭을 닫으면 최근 파일 목록이 있는 시작 화면이 나옵니다. 목록의 파일을 누르거나 파일을 끌어다 놓아 다시 열 수 있습니다.

![모든 탭을 닫은 뒤의 시작 화면](../reports/screenshots/20260926_171856_welcome.png)

### 파일 탐색기에서 끌어다 놓기

1. 파일 탐색기에서 Markdown 파일을 하나 또는 여러 개 선택합니다.
2. 선택한 파일을 MarkdownEditor의 편집기나 미리보기 위로 끌어와 마우스 단추를 놓습니다. 탭 표시줄이나 시작 화면에 놓아도 됩니다.
3. 파일마다 새 탭이 열립니다. 이미 열린 파일이면 그 탭으로 이동합니다.

- 원본 파일은 읽기만 하며 옮기거나 바꾸지 않습니다. 편집기 본문에 파일 경로가 입력되지도 않습니다.
- 폴더, 그림 파일, 인터넷 주소처럼 열 수 없는 항목은 상태 표시줄에 이유가 나오고 열리지 않습니다.
- 편집기 안에서 글자를 끌어 옮기거나 다른 프로그램의 글을 끌어다 놓는 동작은 예전처럼 글자가 입력됩니다.

## 4. 편집과 미리보기

원문을 입력하고 약 300ms 동안 입력을 멈추면 미리보기가 갱신됩니다. 굵게, 기울임, 제목, 인용, 목록, 링크, 이미지, 표, 코드 블록, Mermaid 버튼을 사용할 수 있습니다.

로컬 이미지는 문서가 있는 폴더를 기준으로 찾습니다. 없는 이미지는 빈 공간 대신 오류 상자로 표시됩니다. 넓은 표는 표 영역 안에서 가로로 스크롤할 수 있습니다.

### 들여쓰기와 줄바꿈

- `Tab` 키는 언제나 탭 문자 대신 공백 2칸을 입력합니다. 여러 줄을 선택한 뒤 누르면 선택한 각 줄 앞에 공백 2칸을 추가합니다.
- `편집 > 들여쓰기`는 기본으로 체크되어 있습니다. 체크 상태에서 `Enter`를 누르면 현재 줄의 앞쪽 공백을 다음 줄에도 유지합니다. 체크를 끄면 앞쪽 공백은 유지하지 않습니다.
- 인용(`>`), 글머리 목록(`-`, `+`, `*`), 할 일 목록(`- [ ]`), 번호 목록(`1.`, `1)`)에서 `Enter`를 누르면 다음 줄에 같은 표식을 자동으로 입력합니다. 번호 목록은 번호를 1 증가시킵니다.
- 이 설정은 다음 실행에도 유지됩니다.

### 화면 테마

`보기 > 다크 모드`를 켜면 메뉴, 툴바, 편집기, 미리보기가 다크 모드로 바뀝니다. 라이트 모드의 편집기 배경은 흰색이고 다크 모드에서는 검은색입니다. Markdown 제목·링크·HTML 등의 구문 색상은 각 배경에서 읽기 쉽게 함께 바뀝니다. 편집기 스크롤바는 위치를 쉽게 찾을 수 있도록 두 테마 모두 같은 밝은 색을 사용합니다.

### 글자 크기

상태 표시줄 오른쪽의 `-`와 `+`를 누르거나 편집기·미리보기 위에서 `Ctrl` 키를 누른 채 마우스 휠을 움직입니다. 편집기와 미리보기 글자 크기가 동시에 바뀌며 8~24 단계 안에서 유지됩니다. 기본값은 12입니다.

### 글간격

`보기 > 글간격 크게`를 누를 때마다 왼쪽 편집기의 글자 사이 간격이 5%씩 넓어지고, `보기 > 글간격 작게`를 누르면 5%씩 좁아집니다. 기본값은 100%이고 80%에서 150% 사이에서만 바뀌며, 끝에 닿으면 해당 메뉴가 흐리게 바뀝니다. 바뀐 값은 상태 표시줄 `간격 105%`처럼 표시되고 열려 있는 모든 탭과 새로 여는 탭에 적용되며, 다음 실행 때도 유지됩니다. `보기 > 글간격 기본값`을 누르면 100%로 돌아갑니다. 오른쪽 미리보기와 줄 번호의 간격은 바뀌지 않습니다.

### 보기 모드와 자동 줄바꿈

`보기` 메뉴의 `편집+미리보기`, `편집만`, `미리보기만` 중 지금 쓰는 모드에 체크 표시가 붙습니다. 보기 모드와 `자동 줄바꿈` 설정은 모든 탭에 적용되고 다음 실행 때도 유지됩니다. `편집만` 모드에서는 미리보기를 그리지 않고 기다렸다가, 미리보기를 다시 보이게 하면 최신 내용으로 그립니다.

![편집기 글간격 150%(미리보기는 그대로)](../reports/screenshots/20260926_171856_spacing_150.png)

### Sync Scroll

오른쪽 툴바 영역의 `Sync Scroll`을 체크하면 편집기와 미리보기가 원문 줄 번호를 기준으로 양방향 이동합니다. 제목, 긴 표, 이미지처럼 양쪽 표시 높이가 크게 달라도 같은 원문 위치에 해당하는 내용을 찾습니다. 스크롤 이벤트는 짧게 묶어서 처리하고, 프로그램이 상대 창을 이동시킨 이벤트는 다시 전달하지 않아 반복 이동을 방지합니다. Viewer에서 스크롤해도 편집기의 커서와 선택 영역은 유지됩니다.

`Sync Scroll 위치맞춤`은 편집기의 첫 번째 보이는 줄을 기준으로 Viewer를 즉시 다시 맞춥니다. `Sync Scroll` 체크가 꺼져 있어도 한 번의 강제 정렬을 수행합니다. 문서를 연 직후나 편집으로 미리보기를 다시 그리는 동안에는 버튼이 비활성화되고, 렌더링이 끝나면 자동으로 활성화됩니다. 완료 결과는 상태 표시줄에 나타납니다.

## 5. Mermaid 작성

툴바의 `Mermaid` 버튼을 누르면 flowchart 예제가 삽입됩니다. 다이어그램은 프로그램에 포함된 Mermaid 엔진으로 그리므로 인터넷 연결이 필요 없습니다. 라이트·다크 모드 전환 시 다이어그램도 해당 모드에 맞게 다시 그려집니다. 다크 모드에서는 flowchart의 연결선·화살표·레이블과 sequenceDiagram의 메시지 선·글자에 고대비 색상을 적용하며, 주요 선과 글자는 배경 대비 4.5:1 이상을 자동 검사합니다. 문법 오류가 있으면 해당 블록만 오류로 표시되고 나머지 문서는 계속 보입니다.

## 6. 저장

`Ctrl+S`는 원본을 덮어쓰지 않고 같은 폴더에 날짜 파일을 만듭니다.

- `문서.md` → `문서_20260919.md`
- `문서_20260918.md` → `문서_20260919.md`

같은 파일이 이미 있으면 덮어쓰기, `_2` 같은 번호 붙여 저장, 취소 중 하나를 선택합니다. 저장할 파일이 다른 탭에 열려 있으면 그 탭의 내용을 지키기 위해 덮어쓰기는 고를 수 없고 번호 붙여 저장이나 취소만 할 수 있습니다. `다른 이름으로 저장`으로 다른 탭에 열린 파일을 고르면 저장하지 않고 그 탭을 보여 줍니다. 다른 폴더로 저장하면 상대 이미지·링크가 끊길 수 있으므로 경고를 확인하십시오.

## 7. 안전과 개인정보

- 문서 안의 `script`, 이벤트 속성, 위험 URL은 실행하지 않습니다.
- 링크는 자동으로 열지 않고 사용자가 클릭한 경우에만 처리합니다.
- 외부 이미지는 기본 차단합니다.
- 문서 본문 전체를 로그로 남기지 않습니다.

## 8. 문제 해결

- 미리보기가 검으면 `run_markdowneditor.bat --disable-gpu`로 실행합니다.
- `'sync'은(는) ...`처럼 배치 명령이 조각나 실행되면 프로젝트의 최신 `run_markdowneditor.bat`로 교체합니다. 최신 파일은 Windows용 CRLF 형식입니다.
- 파일을 끌어다 놓아도 열리지 않으면 프로그램을 관리자 권한으로 실행하지 않았는지 확인합니다. Windows는 일반 권한 파일 탐색기에서 관리자 권한 프로그램으로 끌어다 놓는 것을 막습니다.
- 이미지가 없으면 Markdown 파일 옆의 `_assets` 폴더를 확인합니다.
- CP949 문서에 이모지 등을 입력하면 UTF-8로 저장해야 합니다.
- GUI 검증은 화면이 있는 실제 Windows 로그인 세션에서 실행해야 합니다.
