# 설계 결정 기록

## 2026-09-26 macOS 이식

- Python 3.12와 기존 `uv.lock`을 유지한다. 시스템 Python 3.14는 변경하지 않으며 macOS 전용 가상 환경을 준비한다.
- Qt는 macOS에서 `Ctrl`/`ControlModifier`를 Command로 매핑하므로 기존 편집·저장·서식 키를 유지한다. 바꾸기는 `⇧⌘H`, 줄로 이동은 `⌘L`, 탭 이동은 `Meta+Tab`(물리적인 Control+Tab)으로 충돌을 피한다.
- Finder/Dock 전달은 `QApplication.event()`의 `FileOpen` 처리로 구현한다. 전역 Python 이벤트 필터는 QtWebEngine 내부 객체 생성 중 PySide 래퍼 충돌이 발생해 사용하지 않는다.
- 대소문자 판정은 운영체제 경로 정규화와 `os.path.samefile()`을 조합한다. POSIX 경로 전체를 소문자로 만들지 않아 대소문자 구별 APFS에서도 서로 다른 파일을 보존한다.
- Windows의 DLL·Qt 플러그인 용량 최적화는 Windows 빌드에만 적용한다. Mac에서는 Qt 프레임워크를 유지하고 `BUNDLE`로 앱을 만든다. `argv_emulation=False`를 유지해 Qt가 Apple 파일 열기 이벤트를 직접 받는다.
- 현재 Mac의 arm64 빌드와 자동 GUI 검사를 완료했다. Intel·Windows 재검증과 실제 Finder/Dock의 수동 확인은 별도로 구분한다.

## 2026-09-19

1. 제품명, 배포 패키지명, import 패키지명을 모두 `MarkdownEditor`/`markdowneditor`로 통일한다.
2. Python 3.12와 uv 잠금 파일을 사용한다.
3. 시스템 Python·npm 상태에 의존하지 않고 프로젝트 내부 uv 캐시와 Python 설치 디렉터리를 사용한다.
4. 미리보기는 PySide6 QtWebEngine, 변환은 markdown-it-py를 사용한다.
5. 문서 HTML은 데이터로 취급해 Python 정화기, CSP, WebEngine navigation 차단을 함께 적용한다.
6. 외부 이미지는 개인정보 보호를 위해 기본 차단한다.
7. 편집하지 않은 저장은 원본 바이트를 그대로 쓰고, 편집 저장은 원래 인코딩·BOM·대표 줄바꿈을 복원한다.
8. 샘플 원본은 읽기 전용으로 취급하고 저장 검증은 임시 복사본에서 수행한다.
9. Pretendard Regular·Medium·Bold를 배포물에 포함해 편집기와 미리보기의 한글 표시를 통일한다.
10. 1차 PRD의 편집기 검은 배경 요구는 2차 PRD가 구체화한 테마 동작을 최종 기준으로 삼아, 라이트 모드에서는 흰색이고 다크 모드에서는 검은색으로 구현한다.
11. 편집기 스크롤바는 2차 PRD에 따라 라이트·다크 모드 모두 동일한 밝은 팔레트를 사용한다.
12. 초기 동기 스크롤은 절대 픽셀 대신 문서 높이 비율을 사용했다. 이 결정은 2026-09-20의 줄 번호 기반 결정으로 대체한다.
13. 샘플 파일의 SHA-256이 기준선과 달라지면 자동 갱신하지 않고 `BASELINE_CHANGED`로 보고해 앱 회귀와 입력 교체를 구분한다.

## 2026-09-20

14. 편집기의 들여쓰기 단위는 공백 2칸으로 고정하고 `Tab` 입력도 실제 탭 문자를 남기지 않는다.
15. `편집 > 들여쓰기`는 선행 공백 유지 여부만 제어하며, Markdown 인용·목록·번호 표식 자동 계속은 항상 제공한다.
16. 번호 목록은 기존 구분자(`.` 또는 `)`)를 유지하면서 숫자를 1 증가시키고, 완료된 할 일 표식은 다음 줄에서 미완료(`[ ]`)로 시작한다.
17. Sync Scroll은 서로 다른 렌더 높이에서 발생하는 비율 오차를 없애기 위해 원문 `data-line` 기준점과 구간 보간을 사용한다.
18. 원문 HTML 블록 앞에도 높이 0의 줄 기준점을 삽입해 대형 HTML 표가 많은 문서의 위치 계산에 포함한다.
19. `Sync Scroll 위치맞춤`은 체크박스와 독립적인 단발 보정이며, 편집기의 첫 번째 보이는 줄을 Viewer 상단 기준으로 맞춘다.
20. 렌더링 중에는 위치맞춤 버튼을 비활성화하고, 양방향 실시간 동기화는 30ms 단위로 이벤트를 합치며 편집 커서와 선택을 보존한다.
21. Mermaid는 라이트 모드에서 기본 테마를 유지하고, 다크 모드에서는 `base` 테마와 명시적인 선·글자·노트·활성화 색상 변수를 적용해 문서 테마와 함께 다시 렌더링한다.
22. Mermaid 다크 모드 회귀는 실제 SVG의 계산된 색상을 기준으로 flowchart 연결선·화살촉·레이블과 sequenceDiagram 메시지 선·텍스트를 측정하며, 각 항목의 배경 대비 4.5:1 이상을 인수 기준으로 삼는다. Mermaid 버전별 스타일 차이에 대비한 CSS 보정은 해당 SVG 요소에만 제한한다.

23. Windows 배포 번들에는 앱이 실제로 로드하는 Qt 구성 요소만 넣는다. QML 모듈과 이를 따라 들어오는 Qt 3D·Charts·Multimedia 등의 DLL, 쓰지 않는 PySide6 바인딩, WebEngine 디버그·DevTools 리소스, 한국어 이외의 번역(Chromium 대체용 `en-US.pak`은 유지), 사용하지 않는 Qt 플러그인은 `packaging/MarkdownEditor.spec`에서 제외하고, 다시 포함되면 `scripts/build_windows.py`가 빌드를 실패시킨다. `opengl32sw.dll`은 GPU가 없는 PC의 대체 경로일 수 있어 유지한다.

## 2026-09-26 (4차 기능보완)

24. 보기 메뉴 이름은 사용자가 PRD에 적은 그대로 `글간격 크게`, `글간격 작게`로 한다(GPT v0.2 프롬프트의 "글자 간격" 대신).
25. 글간격은 편집기 본문 글자 사이 간격(자간)이며 `QFont.SpacingType.PercentageSpacing`으로 적용한다. 기본 100%, 한 단계 5%p, 범위 80~150%이고 경계에서는 해당 메뉴를 비활성화한다(상태 표시줄 글자 크기 `-`/`+`와 같은 방식). 미리보기와 줄 번호는 바꾸지 않으며, 줄 번호 영역은 100% 글꼴로 그리고 폭도 그 글꼴로 계산한다. 설정 키는 `view/letter_spacing`, 숫자가 아니거나 없으면 100%, 범위 밖이면 가까운 경계값으로 복원한다.
26. 편집기 글꼴은 `gui.fonts.editor_font(size, spacing)` 한곳에서 만든다. 글자 크기 변경이 글간격을 지우던 구조(`set_markdown_font_size()`가 새 `QFont`를 만듦)를 없애기 위한 것이다.
27. 탭 하나는 `DocumentSession` 하나이며 문서·편집기·미리보기·렌더·동기화 상태를 모두 가진다. `MainWindow`는 메뉴·액션, 전역 보기 설정, 최근 파일, 탭 관리, 종료만 맡는다. 기존 호출부를 위해 `editor`, `preview`, `document_data`는 활성 세션을 돌려주는 읽기 전용 속성으로 남긴다.
28. 마크다운 툴바는 초안 PRD의 배치대로 각 탭의 편집기 바로 위에 둔다. 서식 `QAction`은 창마다 한 벌(`MarkdownActions`)만 만들고 탭별 툴바 위젯이 같은 액션을 표시해 단축키가 중복되지 않게 한다.
29. 같은 파일 판정은 `os.path.normcase(os.path.realpath())` 키와 `os.path.samefile()`을 함께 쓴다. 실측(2026-09-26): 대소문자·`/`·`\`·`..`·상대 경로 차이는 같은 키가 되고, 하드 링크는 `samefile`로, C: 드라이브의 8.3 짧은 이름은 `realpath`가 긴 이름으로 바꿔 같은 키가 된다. 프로젝트가 있는 F: 드라이브에는 8.3 이름이 없다. 심볼릭 링크는 이 PC에서 관리자 권한 없이 만들 수 없어(WinError 1314) 확인하지 못했다.
30. 파일을 새로 열면 항상 새 탭으로 열고 다른 탭의 저장 여부를 묻지 않는다. 이미 열린 파일은 새 탭 대신 그 탭을 활성화하고 다시 읽지 않는다. 마지막 탭을 닫아도 앱은 끝나지 않고 시작 화면(안내 문구, 열기, 최근 파일)으로 돌아가며 빈 새 문서는 만들지 않는다.
31. 저장 대상이 다른 탭에 열린 파일이면 덮어쓰지 않는다. 날짜 저장은 [번호 붙여 저장] [취소]만 제공하고, 번호를 붙일 때도 다른 탭에 열린 경로를 건너뛴다. 다른 이름으로 저장은 충돌을 알리고 저장하지 않은 채 그 탭을 활성화한다.
32. 외부 이미지 요청 차단기(`NetworkGuard`)는 앱 전체에 하나만 두고 공유 기본 프로필에 한 번 설치한다. 기존 구조는 미리보기마다 차단기를 다시 설치하고 닫을 때 해제해, 탭을 늘리면 탭 하나를 닫을 때 모든 탭의 차단기가 사라질 수 있었다. 해제는 마지막 창을 닫을 때와 `app.py` 종료 때만 한다.
33. 끌어다 놓기: 미리보기 페이지에 `NavigateOnDropEnabled=False`를 두고, 편집기(viewport 포함)와 WebEngine 렌더 위젯에 공통 이벤트 필터를 설치하며, 메인 프레임 이동은 셸 로드(`data:`)와 Chromium 내부 `about:`만 허용한다. `about:`은 Chromium이 페이지를 정리할 때 쓸 수 있어 예방적으로 허용했다(막았을 때의 문제를 실측으로 확인한 것은 아니다). `setHtml()` 셸 로드가 메인 프레임 `data:` 이동으로, 로컬 파일 로드가 `file:` 이동으로 들어오는 것은 실측으로 확인했다. 파일 드롭은 항상 `CopyAction`으로 받고 `acceptProposedAction()`을 쓰지 않는다. 편집기는 로컬 파일이 없는 드래그(글 옮기기, 다른 앱의 글, 웹 링크 글)를 기본 동작으로 둔다.
34. 열 수 있는 파일이 없는 드래그는 거부한다. Qt는 거부된 드래그에 Drop을 보내지 않으므로(실측) 이유는 드래그 중 상태 표시줄에 보여 준다. 드롭한 파일이 모두 열기에 실패한 경우에만 대화상자로 이유를 보여 준다.
35. 여러 파일을 한 번에 열 때 WebEngine 셸(Mermaid 3.6MB 포함)은 탭을 처음 볼 때 불러온다. 탭 수는 제한하지 않고 메모리는 검증 보고서에 기록한다.
36. 상태 표시줄의 경로 표시는 임시 메시지가 있는 동안 명시적으로 숨긴다. QStatusBar는 메시지 동안 이 라벨을 암시적으로만 숨겨, 테마 변경 같은 재배치 뒤 메시지와 경로가 겹쳐 보였다(캡처 확인 중 발견).
37. 현재 탭은 탭 표시줄 스타일로 위쪽 굵은 막대와 굵은 글씨로 표시한다. 기본 Windows 스타일에서는 활성 탭이 글자 밝기로만 구분되어 잘 보이지 않았다(캡처 확인 중 발견).
38. 명령줄은 파일을 여러 개 받는다(`nargs="*"`, 옵션과 섞어 쓸 수 있게 `parse_intermixed_args`). `run_markdowneditor.bat`에 여러 파일을 놓으면 인자 오류로 실행되지 않던 문제를 없앤다.
39. 4차 프롬프트 §3.2의 사용자 결정은 답을 받기 전이라 기본값을 따른다: 설문지 샘플 기준선은 고치거나 복원하지 않고 `BASELINE_CHANGED`로 보고한다. 버전은 0.1.0을 유지하고 빌드 기록에 커밋 해시와 빌드 시각을 남긴다. git 브랜치·커밋은 만들지 않는다.
40. 샘플 검증기의 사람 확인 항목(S14 화면, S29 실제 Explorer 끌어다 놓기)은 이미 만든 보고서에 사후 기록한다(`--confirm-visual`, `--confirm-explorer-drop`). 기록할 때 확인한 파일의 SHA-256을 보고서에 남겨, 확인하지 않은 새 캡처에 통과가 붙지 않게 한다. 공유 요청 차단기의 차단 수는 창 사이에 누적되므로 보안 검사는 해당 문서를 여는 동안의 차이로 계산한다.
41. 탭 관리 편의 기능(4차 프롬프트의 [선택] 항목)을 추가한다: 탭 오른쪽 클릭 메뉴(탭 닫기, 다른 탭 닫기, 모든 탭 닫기, 파일 위치 열기, 전체 경로 복사), `파일` 메뉴의 `다른 탭 닫기`·`모든 탭 닫기`, 가운데 단추 클릭으로 탭 닫기, `보기 > 글간격 기본값`. 여러 탭을 닫을 때는 탭 순서대로 확인하고 첫 [취소]에서 멈춘다. 새 단축키는 추가하지 않았다(기존 단축키와의 충돌 방지).
42. `자동 줄바꿈`(`view/word_wrap`)과 보기 모드(`view/mode`)를 저장·복원한다. 보기 모드 메뉴는 서로 배타적인 체크 항목으로 바꿔 현재 모드를 보인다. 저장된 보기 모드 값이 잘못되면 `편집+미리보기`로 복원한다.
43. `편집만` 모드에서는 미리보기가 숨겨져 Chromium이 애니메이션 프레임을 멈추므로, 렌더 완료 보고는 미리보기를 다시 보이게 한 뒤에 온다(`편집만` 모드에서 실측). 보이지 않는 다른 탭도 같은 이유로 늦게 보고될 수 있다(따로 측정하지 않음). 사용자에게 보이지 않는 동안이라 그대로 두고, 테스트는 미리보기를 다시 보이게 한 뒤 완료를 확인한다.
