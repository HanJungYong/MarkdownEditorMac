# 설계 결정 기록

## 2026-09-19

1. 제품명, 배포 패키지명, import 패키지명을 모두 `MarkdownEditor`/`markdowneditor`로 통일한다.
2. Python 3.12와 uv 잠금 파일을 사용한다.
3. 시스템 Python·npm 상태에 의존하지 않고 프로젝트 내부 uv 캐시와 Python 설치 디렉터리를 사용한다.
4. 미리보기는 PySide6 QtWebEngine, 변환은 markdown-it-py를 사용한다.
5. 문서 HTML은 데이터로 취급해 Python 정화기, CSP, WebEngine navigation 차단을 함께 적용한다.
6. 외부 이미지는 개인정보 보호를 위해 기본 차단한다.
7. 편집하지 않은 저장은 원본 바이트를 그대로 쓰고, 편집 저장은 원래 인코딩·BOM·대표 줄바꿈을 복원한다.
8. 샘플 원본은 읽기 전용으로 취급하고 저장 검증은 임시 복사본에서 수행한다.
9. Pretendard Regular·Medium·Bold를 배포물에 포함해 편집기와 미리보기의 한글 표시를 통일한다.
10. 1차 PRD의 편집기 검은 배경 요구는 2차 PRD가 구체화한 테마 동작을 최종 기준으로 삼아, 라이트 모드에서는 흰색이고 다크 모드에서는 검은색으로 구현한다.
11. 편집기 스크롤바는 2차 PRD에 따라 라이트·다크 모드 모두 동일한 밝은 팔레트를 사용한다.
12. 초기 동기 스크롤은 절대 픽셀 대신 문서 높이 비율을 사용했다. 이 결정은 2026-09-20의 줄 번호 기반 결정으로 대체한다.
13. 샘플 파일의 SHA-256이 기준선과 달라지면 자동 갱신하지 않고 `BASELINE_CHANGED`로 보고해 앱 회귀와 입력 교체를 구분한다.

## 2026-09-20

14. 편집기의 들여쓰기 단위는 공백 2칸으로 고정하고 `Tab` 입력도 실제 탭 문자를 남기지 않는다.
15. `편집 > 들여쓰기`는 선행 공백 유지 여부만 제어하며, Markdown 인용·목록·번호 표식 자동 계속은 항상 제공한다.
16. 번호 목록은 기존 구분자(`.` 또는 `)`)를 유지하면서 숫자를 1 증가시키고, 완료된 할 일 표식은 다음 줄에서 미완료(`[ ]`)로 시작한다.
17. Sync Scroll은 서로 다른 렌더 높이에서 발생하는 비율 오차를 없애기 위해 원문 `data-line` 기준점과 구간 보간을 사용한다.
18. 원문 HTML 블록 앞에도 높이 0의 줄 기준점을 삽입해 대형 HTML 표가 많은 문서의 위치 계산에 포함한다.
19. `Sync Scroll 위치맞춤`은 체크박스와 독립적인 단발 보정이며, 편집기의 첫 번째 보이는 줄을 Viewer 상단 기준으로 맞춘다.
20. 렌더링 중에는 위치맞춤 버튼을 비활성화하고, 양방향 실시간 동기화는 30ms 단위로 이벤트를 합치며 편집 커서와 선택을 보존한다.
21. Mermaid는 라이트 모드에서 기본 테마를 유지하고, 다크 모드에서는 `base` 테마와 명시적인 선·글자·노트·활성화 색상 변수를 적용해 문서 테마와 함께 다시 렌더링한다.
22. Mermaid 다크 모드 회귀는 실제 SVG의 계산된 색상을 기준으로 flowchart 연결선·화살촉·레이블과 sequenceDiagram 메시지 선·텍스트를 측정하며, 각 항목의 배경 대비 4.5:1 이상을 인수 기준으로 삼는다. Mermaid 버전별 스타일 차이에 대비한 CSS 보정은 해당 SVG 요소에만 제한한다.

## 2026-09-25

23. Windows 배포 번들에는 앱이 실제로 로드하는 Qt 구성 요소만 넣는다. QML 모듈과 이를 따라 들어오는 Qt 3D·Charts·Multimedia 등의 DLL, 쓰지 않는 PySide6 바인딩, WebEngine 디버그·DevTools 리소스, 한국어 이외의 번역(Chromium 대체용 `en-US.pak`은 유지), 사용하지 않는 Qt 플러그인은 `packaging/MarkdownEditor.spec`에서 제외하고, 다시 포함되면 `scripts/build_windows.py`가 빌드를 실패시킨다. `opengl32sw.dll`은 GPU가 없는 PC의 대체 경로일 수 있어 유지한다.
