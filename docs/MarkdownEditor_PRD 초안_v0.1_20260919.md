# Markdown Editor GUI 프로그램 개발 프롬프트

> - 작성: 2026-09-19
> - 프로젝트 루트: `F:\38.AICowork\202609_MarkdownEditor`


## 0. 한눈에 보기

- **만들 것**: 마크다운 문서 1개를 입력 받아 보여주고 수정할 수 있는, GUI 프로그램 `MarkdownEditor`.
- **처리 흐름**: 마크다운 파일 입력 검증 → 마크다운 파일 내용 화면 출력  → 마크다운 내용 수정 → 마크다운 파일 저장.
- **검증은 정직하게**: 실행하지 못한 검사는 `NOT_CHECKED`. 가상 결과나 과장된 통과 표시를 하지 않는다.
- **환경**: uv로 Python·패키지를 재현한다(`.python-version`, `pyproject.toml`, `uv.lock`).

### 1.1 배경

AI와 작업을 하기 위해 마크다운 문서를 보고 수정할 일이 많지만, 웹 이나 다른 마크다운 에디터는 불편하다.
특히 마크다운 문서에 연결이 되어 있는 이미지나 요소들이 있으면 웹페이지에서 보여주는 마크다운 문서는 제대로 보이지 않는다.

### 1.2 역할

너는 AI, Python, 문서 포맷, Windows 자동화, 데스크톱 GUI에 능숙한 시니어 개발자다. 
설명이나 설계 제안에서 멈추지 말고, 이 프롬프트를 충족하는 실행 가능한 프로그램, 의미 있는 테스트, 한국어 사용자 문서까지 구현한다. 
프로그램 이름은 `MarkdownEditor`, Python 패키지는 `markdowneditor`로 한다.

### 1.3 목표

- 연결이 되어 있는 이미지나 요소들이 있는 마크다운 문서도 잘 보여주고, 쉽게 편집할 수 있는 마크다운 Viewer 이자 Editor 개발.
- 비개발자도 쓸 수 있는 한국어 GUI.
- 다른 PC에서 재현할 수 있는 uv 기반 설치·실행.

### 1.4 요구사항

- 입력 항목
  - 조회나 수정을 위한 마크다운 파일: 1개의 마크다운 파일
- Windows Python 기반 GUI 프로그램 
- 마크다운 출력 화면 구성
  - 크게 2개의 화면으로 구성.
  - 왼쪽 화면은 마크다운 원문을 보여 주는 에디터.
    - 위쪽에 에디팅을 도와주는 마크다운 툴바가 필요함.
  - 오른쪽 화면은 왼쪽 마크다운을 실시간으로 보여주는 Viewer 화면.
    - 연결이 되어 있는 이미지나 요소들이 있는 마크다운 문서도 이미지 나 연결 요소들이 잘 보여야 함.   
    - mermaid flowchart 도 잘 보여야 함.

- 메뉴에서 마크다운 파일 저장 기능
  - 저장시 기존 파일명에 날짜를 붙여서 저장함.
