# Markdown Editor GUI 프로그램 1차 기능 보완 PRD 요구사항


## Dark 모드 추가 
  - 메뉴의 보기에 다크모드 표시
  - 다크모드 선택시 다크모드 출력.

## 왼쪽 에디팅 창 수정 
  - 선택된 라인을 표시하는 하일라이트 바를 표시하지 않음.
  - 왼쪽 에디팅 창의 배경색은 검은 색으로 수정.

## 마크다운 글짜 사이즈 조절 기능 추가
  - 창의 아래 Status 바를 추가 하고 Status 에 +, - 를 넣어서 마크다운 글짜 사이즈를 조절 가능하게 추가.
  - 키보드 Ctrl Key 와 마우스 휠의 조합으로도 사이즈 조절 가능하게 함.
    - 현재 오른쪽 Viewer 창은 사이즈 조절이 가능하지만, 왼쪽 에디팅 창은 사이즈 조절이 안되어 오른쪽 Viewer 창은 사이즈 조절이 가능하게 변경.
  - 왼쪽 에디팅 창과 오른쪽 Viewer 창의 글짜 사이즈가 동시에 조절이 됨.

## 마크다운 글짜 사이즈 2단계 크게 함
  - 현재 마크다운 글짜 사이즈 가 너무 작아서 잘 안 보임.
  - 왼쪽 에디팅 창과 오른쪽 Viewer 창의 글짜 사이즈 모두 적용

## Sync Scroll 기능 추가  
  - 문제점: 왼쪽 에디팅 창과 오른쪽 Viewer 창의 스크롤이 따로 따로 움직여서 불편하다.
  - Sync Scroll Checkbox 추가
    - 기능: 
      - Checkbox 를 check 하면, 현재 시점의 왼쪽 에디팅 창과 오른쪽 Viewer 창의 스크롤이 한번에 함께 움직이게 한다. 
      - Checkbox 를 check 하지 않으면, 현재 시점의 왼쪽 에디팅 창과 오른쪽 Viewer 창의 스크롤이 따로 따로 움직이게 한다. 
    - Checkbox 위치
      - 왼쪽 에디팅 창의 마크다운 내용 출력 시작 위치와 오른쪽 Viewer 창의 마크다운 내용 출력 시작 위치를 왼쪽 에디팅 창에 맞추면,
        오른쪽 Viewer 창의 윗부분에 빈공간이 생기는 데, 이 빈공간에 Sync Scroll Checkbox 를 넣는다.
