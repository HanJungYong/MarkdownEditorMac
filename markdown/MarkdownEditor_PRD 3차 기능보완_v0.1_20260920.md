# Markdown Editor GUI 프로그램 3차 기능 보완 PRD 요구사항

## 왼쪽 에디팅 창 편집 모드 수정
  - 들여쓰기 
    - 들여쓰기 크기는 2.
    - 들여쓰기는 tab 을 눌러도 항상 공백 문자로 변경.
    - 줄바꿈시 들여쓰기 적용.
      - 편집 메뉴에 `들여쓰기` 메뉴 추가
        - `들여쓰기` 가 체크 되어 있으면 줄바꿈시 들여쓰기 적용 (Enter 입력 시 체크 상태이면 기존 선행 공백을 유지).
        - `들여쓰기` 가 체크 되어 있지 않으면 줄바꿈시 들여쓰기 적용하지 않음.
        - 기본 체크 상태
  
  - 줄바꿈시 편의 기능 제공
    - 기존 편집하고 있는 마크다운 태그가 인용, 목록, 번호 이면 줄바꿈시 계속 인용, 목록, 번호로 시작함.
    - 번호 목록은 다음 번호로 증가하도록 구현
    - 편집 메뉴에 `들여쓰기` 가 체크 되어 있으면 줄바꿈시 들여쓰기 적용.
