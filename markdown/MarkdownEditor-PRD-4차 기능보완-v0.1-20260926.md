# Markdown Editor GUI 프로그램 4차 기능 보완 PRD 요구사항


### 왼쪽 에디팅 창 편집 모드 설정 
  - 글자 글간격 설정 기능 
    - Top 메뉴의 보기 메뉴 에 글간격 크게, 글간격 작게 추가.
    - `글간격 크게` 하면 에디팅 창의 글자의 글자 간격을 1단계 씩 크게 한다.
    - `글간격 작게` 하면 에디팅 창의 글자의 글자 간격을 1단계 씩 작게 한다.
    
### 문서 Tab 기능 추가 
  - 문제점: 1개의 마크다운만 편집이 가능해서 여러 마크다운을 편집할 때 불편하다.
  - 문서 Tab 을 상단에 추가하여 여러 파일을 편집할 수 있게 한다.
  - 문서 Tab 별로 1개의 마크다운 파일을 편집하고 볼수 있다. 

### 마우스 Drag & Drop 으로 파일 열기 
  - 마우스의 Drag & Drop 기능으로 Explorer 에 있는 마크다운 파일을 열수 있다.
  - Explorer 에 있는 마크다운 파일을 에디팅 창이나 Viewer 창에 Drag & Drop 하면 파일을 열수 있다.
